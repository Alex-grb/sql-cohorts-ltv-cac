# SQL-аналитика: Когорты, Retention, LTV/CAC

Кейс по продуктовой аналитике: расчет метрик и оценка окупаемости маркетинга на SQL (PostgreSQL).

## Задача
Понять, какие каналы привлечения клиентов окупаются, и куда перераспределить маркетинговый бюджет. 

## Данные
Синтетические данные интернет-магазина в PostgreSQL (3 таблицы):
* `port_customers` — 20 клиентов: id, дата регистрации, канал привлечения.
* `port_orders` — 18 заказов: id, клиент, дата, сумма.
* `port_costs` — затраты на привлечение по каналам: google, yandex, vk.

## Методология
* **Когорты:** выделены по месяцу первого заказа клиента.
* **Retention:** процент клиентов когорты, вернувшихся через 1, 2, 3 месяца.
* **LTV:** средняя выручка с клиента за всё время.
* **CAC:** затраты на привлечение одного клиента (бюджет канала / число клиентов).
* **LTV/CAC:** норма > 1, значение < 1 означает убыточность.

## Результаты
* **Общий LTV:** 2 415 ₽
* **Общий CAC:** 5 000 ₽
* **Вывод:** бизнес убыточен, так как LTV/CAC < 1.

| vk | 1 683.33 | 2 500.00 | 0.67 |
| google | 3 305.00 | 7 142.86 | 0.46 |
| yandex | 1 960.00 | 5 000.00 | 0.39 |

### Рекомендации
1. Перераспределить бюджет в пользу канала **vk** (самый высокий LTV/CAC).
2. Снизить CAC в google и yandex.
3. Повысить Retention и частоту повторных покупок, чтобы увеличить LTV.
